# نقطة × دائرة

لعبة عربية محلية للاعبين على جهاز واحد، بتصميم Cosmic Neon Arena. لا توجد حسابات أو خدمات خلفية أو تنزيلات خطوط أو ملفات صوت خارجية.

## التشغيل

يتطلب المشروع Node.js 22 أو أحدث وnpm.

```bash
npm ci
npm run dev
```

افتح http://localhost:3000. لبناء وتشغيل نسخة الإنتاج:

```bash
npm run build
npm start
```

الاتصال بالإنترنت مطلوب لتثبيت الحزم فقط. لا تجري اللعبة طلبات إلى خدمات خارجية أثناء التشغيل. لا يتضمن المشروع Service Worker أو تثبيت PWA.

## البنية

- `app/`: صفحة App Router وتخطيط عربي خادمي وCSS والهوية المحلية.
- `components/`: جذر التفاعل وشاشات البداية واللعب والنوافذ والعناصر المشتركة.
- `hooks/`: حالة اللعبة والتخزين والصوت والاهتزاز.
- `lib/`: منطق اللعبة النقي والتحقق من التخزين والثوابت والتنسيق.
- `types/`: أنواع اللوحة واللاعبين والإعدادات والإحصاءات والأحداث.
- `tests/`: اختبارات المنطق والتخزين واختبارات المتصفح.

`GameApp` هو حد التفاعل العميل. يحدّث reducer نقيّ اللوحة ونتائج المباراة والإحصاءات في انتقال واحد؛ لا تُحتسب النتائج في effects. لا يقرأ العرض الخادمي LocalStorage. تكتمل القراءة قبل تفعيل اللعبة أو كتابة الإعدادات والإحصاءات.

اللوحة «#» كبيرة تضم ٩ لوحات «#» فرعية. تُرسم خطوط اللوحة الكبيرة والفرعية والرموز وخطوط الفوز باستخدام CSS وSVG. إحداثيات اللوحة الداخلية تبدأ من أعلى اليسار حتى تتطابق الخانات مع خط الفوز، فيما تبقى الواجهة والنصوص RTL. أعمدة تسميات قارئ الشاشة مرقّمة من اليسار. تعرض الإحصاءات أرقامًا إنجليزية ثابتة التنسيق.

## القواعد

- يبدأ × المباراة الأولى ويختار أي لوحة فرعية. الحركة التالية إجبارية داخل اللوحة الفرعية المقابلة للخانة التي لُعبت؛ إذا كانت تلك اللوحة محسومة يختار اللاعب أي لوحة فرعية مفتوحة.
- الفوز بلوحة فرعية يضع رمز الفائز × أو ○ في الخانة الكبيرة. امتلاء لوحة فرعية دون فائز يعطيها علامة «=» ويمنع اللعب فيها.
- يربح الجولة من يحسم ثلاث لوحات كبيرة على خط واحد. تعادل «#» الكبيرة يحدث عندما تُحسم كل اللوحات الفرعية دون خط فائز.
- بعد الفوز يبدأ الخاسر؛ بعد التعادل يبدأ اللاعب الذي لم يبدأ الجولة السابقة.
- «جولة جديدة» أثناء اللعب تطلب تأكيدًا، ثم تلغي الجولة دون احتسابها أو تغيير رقمها أو بادئها. بعد اكتمالها تنتقل للجولة التالية.
- «إعادة المباراة» تصفّر نتائج المباراة فقط، وتعيد البادئ إلى × ورقم الجولة إلى 1.
- العودة للرئيسية تنهي المباراة. تُطلب الموافقة إذا كانت الجولة غير مكتملة وبها حركات. تحديث الصفحة ينهي المباراة أيضًا؛ لا تُحفظ اللوحة.
- تُحفظ الإحصاءات بحسب الرمز وليس اسم اللاعب. التعادل يكسر سلسلة الانتصارات. نسبة الفوز هي عدد الانتصارات مقسومًا على جميع الجولات المكتملة، بما فيها التعادلات. عند تساوي أفضل سلسلة تُحفظ السلسلة السابقة.
- تصفير الإحصاءات منفصل عن إعادة الإعدادات والمباراة.

## التخزين والخصائص الاختيارية

المفتاحان هما `nuqta-daira:stats:v1` و`nuqta-daira:settings:v1`. يتحقق التطبيق من JSON والقيم، ويستعيد الافتراضي عند التلف. إذا حُظر التخزين يستمر اللعب في الذاكرة وتظهر رسالة عربية.

تُحفظ الأسماء والإعدادات أثناء التعديل. الأسماء لا تتجاوز 24 حرفًا وتعود للاسم الافتراضي عند ترك الحقل فارغًا. السمات تُطبق فورًا. الصوت والاهتزاز مفعّلان افتراضيًا. ينشأ AudioContext داخل تفاعل المستخدم فقط؛ الاهتزاز اختياري ويعتمد على دعم المتصفح والجهاز.

الإحصاءات مخصصة لجلسة نشطة واحدة؛ ليست مزامنة متعددة التبويبات أو الأجهزة.

## التحقق اليدوي

1. شغّل المشروع بالأوامر أعلاه، وابدأ جولة.
2. لتجربة فوز لوحة فرعية لـ ×، انقر بالإحداثيات `(لوحة، خانة)` بالترتيب `(0,0), (0,1), (1,3), (3,0), (0,4), (4,0), (0,8)`؛ سيظهر رمز × كبير فوق اللوحة 0 ويستمر اللعب. التسلسل الكامل لفوز الجولة بخط قطري كبير موجود في ثابت `BIG_X_DIAG_WIN` داخل `tests/gameLogic.test.ts`. تبدأ إحداثيات كل لوحة من أعلى اليسار وتنتقل إلى اليمين صفًا بعد صف.
3. تحقق من القاعدة الإجبارية: بعد كل حركة يضيء هدف اللوحة الفرعية التالية، وتُقفل سواها؛ إذا كانت اللوحة المستهدفة محسومة يصبح الاختيار حرًا. لوحة فرعية متعادلة تعرض «=» خافتة ولا تُلعب مجددًا.
4. أغلق نافذة النتيجة وتأكد من بقاء اللوحة مقفلة (لا تُستجيب أي خانة)، ثم ابدأ الجولة التالية وتحقق من أن البادئ هو الخاسر.
5. غيّر الأسماء والسمات والصوت ثم أعد تحميل الصفحة؛ افتح الإعدادات وتحقق من بقائها. أكمل جولة وأعد التحميل، ثم افتح الإحصاءات وتحقق من حفظها.
6. جرّب إلغاء تأكيد الحذف ثم الموافقة عليه، وكذلك إعادة المباراة والإعدادات. تحقّق من أن كل إجراء يغيّر البيانات المقصودة فقط.
7. جرّب المقاسات 360×640 و390×844 و768×1024 وسطح المكتب. افحص السمات الثلاث، النص العربي، حواف الأمان وعدم وجود تمرير أفقي. عند قصر الشاشة الشديد أو تكبير النص يُسمح بالتمرير بدل قص المحتوى.
8. استخدم Tab وEnter وSpace وEscape. تُعلن الأدوار والنتائج عبر aria-live، وتحجز النوافذ التركيز وتعيده إلى العنصر السابق. فعّل تقليل الحركة من نظام التشغيل وتحقق من إيقاف الحركة المستمرة.
9. اختبر الصوت بعد نقرة فعلية على الهاتف، والاهتزاز على جهاز يدعم `navigator.vibrate`؛ عدم توفرهما لا يمنع اللعب.
